Codex Response 1 / final_answer

2026-06-15 09:27:44 +0800
不是只能是 HTML。HTML 只是最适合这种“可交互动态连接线”的载体。

常见选择是：

1. **HTML + SVG + CSS/JS**
   当前我做的就是这个。优点是可暂停、可交互、动画流畅，浏览器直接打开。

2. **纯 SVG 动画**
   可以做成一个 `.svg` 文件，里面用 CSS 或 SMIL 做动效。更轻，但交互能力弱一些，某些软件里可能只显示静态。

3. **GIF / APNG**
   适合放进文档、聊天、网页预览，但不可交互，文字和线条可能有压缩损失。

4. **MP4 / WebM**
   适合汇报、PPT、视频材料，效果稳定，但也是不可交互。

5. **`.drawio`**
   适合编辑静态架构图，但 draw.io 的图模型本身主要是静态的，不适合可靠表达“连接线流动”这种动画。可以做静态版本，动态效果通常要靠 HTML/SVG/video 这些外部载体。

所以结论是：**动态不只能是 HTML，但如果要“连接线流动 + 可交互 + 可直接打开”，HTML 是最稳的。**
