看这个仓库的文档，结论是：

它不是“客户端里直接内置 MCP”。普通 Web/桌面客户端就是 Next AI Draw.io 本体，用来自己聊天生成/编辑 draw.io 图。

MCP 是这个仓库里的一个独立 npm 包：`@next-ai-drawio/mcp-server`，路径在 `packages/mcp-server`。官方 README 让你在 Claude Desktop / Cursor / VS Code 这类 MCP 客户端里配置：

```json
{
  "mcpServers": {
    "drawio": {
      "command": "npx",
      "args": ["@next-ai-drawio/mcp-server@latest"]
    }
  }
}
```

也就是说你一般不用手动下载另一个安装包，`npx` 会拉起/下载这个 MCP server 包；但你确实要在 Claude、Cursor、VS Code 等 MCP host 里单独配置它。仓库 README 明确写的是“Use Next AI Draw.io with AI agents ... via MCP”，并给的就是这个 `npx @next-ai-drawio/mcp-server@latest` 配置。MCP server README 也写了它是自包含的 MCP server，带 embedded HTTP server，会开本地浏览器预览，默认端口 `6002`，并提供 `start_session`、`create_new_diagram`、`edit_diagram`、`get_diagram`、`export_diagram` 这些工具。

所以准确说：

- 不是只有壳子，MCP server 是实实在在的工具服务。
- 但普通 client/桌面版不等于已经帮你装好/注册好了 MCP。
- 要用 MCP，就在 Claude/Cursor/VS Code 配 `npx @next-ai-drawio/mcp-server@latest`。
- 它会本地启动一个小 HTTP 服务和浏览器预览；draw.io iframe 默认还是用 `https://embed.diagrams.net`，私有环境可以配 `DRAWIO_BASE_URL` 指向自建 draw.io。

来源：GitHub README 的 MCP 配置说明和 MCP Server README 的安装/工作方式说明。
https://github.com/DayuanJiang/next-ai-draw-io/
https://github.com/DayuanJiang/next-ai-draw-io/blob/main/packages/mcp-server/README.md
