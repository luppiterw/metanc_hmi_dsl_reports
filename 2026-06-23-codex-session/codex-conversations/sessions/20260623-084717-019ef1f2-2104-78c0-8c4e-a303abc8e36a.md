````
- Veo clips 和 soundtrack 是 API/额度消耗，不是免费本地渲染；正式生成前要先确认预算和你是否批准调用。
- registry 显示 `veo` 可用，不等于一定有足够额度；真正调用时还可能遇到 quota/auth/provider failure，需要按 OpenMontage 规则停下来让你选 fallback，比如 Seedance / Kling / Runway / stock+Remotion animatic。

如果要做，我建议先走一个低风险版本：

```text
Create "SIGNAL FROM TOMORROW", a 45-60 second cinematic sci-fi trailer.
Use the cinematic pipeline. Motion is required. Prefer Veo for generated clips, Remotion for final composition, and generate a dark orchestral/electronic soundtrack. Stop for approval before paid asset generation.
```

第一步只做 proposal / script / scene plan 和成本估算，不直接花钱生成 Veo。你确认后再开始资产生成。
````
