Safest local remediation when this happens:

```bash
docker pull --platform linux/amd64 optimalcnc/metanc:latest

docker build --pull=false \
  --target build \
  -f nrt/hmi/docker/hmi-server.Dockerfile \
  -t metanc-hmi-server-build:local \
  nrt/hmi
```

Use this split because `docker pull --platform linux/amd64` makes the local `optimalcnc/metanc:latest` tag match the current published amd64 base, and `docker build --pull=false` prevents the rebuild from silently moving again if `latest` changes during the local repair.
