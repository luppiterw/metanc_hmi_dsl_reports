   Plan: [contract.md:70](/home/iaar/workspace/ccmix-wp/MetaNC/nrt/hmi/docs/project/work_offset/contract.md:70) maps `offset_x -> x`, `offset_y -> y`, etc.; [server_plan.md:105](/home/iaar/workspace/ccmix-wp/MetaNC/nrt/hmi/docs/project/work_offset/server_plan.md:105) repeats that test expectation.

   Impact: real profiles can use IDs like `axis-x` with display name `X`. The planned write will call `set_frame_component(axis_id="x")` and be rejected as `wcs-axis-unsupported`. The adapter must map visible columns through `WorkOffsetViewResult.axes[]` and row `values[]`, not hardcoded letters.
