```text
optimalcnc/metanc:latest              # 统一构建/开发基础
optimalcnc/metanc-rt:latest           # RT simulation runtime
optimalcnc/metanc-hmi-server:latest   # HMI server runtime
```

本地的 `metanc-hmi-server-build:local` 后期可以弱化成 CI/build 过程里的中间层，不一定需要作为用户长期关心的镜像。
