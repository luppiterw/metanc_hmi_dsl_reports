**核心结论**
Micu 的“分组”不是单纯按模型名分，而是按「模型家族 + 调用协议 + 客户端场景」分。接入前要同时对齐 5 件事：分组、协议、Base URL、User-Agent、模型名；任一项错位都可能导致 `403/401`、模型列表为空、长上下文不生效等问题。([docs.micuapi.ai](https://docs.micuapi.ai/external-compat))

**分组矩阵**

| 类别 | 分组 | 主要用途 | model 建议 |
|---|---|---|---|
| 默认/路由 | `default` | 实际路由到 `vip_1_max_enterprise`，文档不建议手动选 | 不建议手动选 |
| Claude 官方/号池 | `vip_1_api_mix`, `vip_1_awsbedrock`, `vip_1_ext`, `vip_1_jupiter`, `vip_1_max_enterprise`, `vip_1_max_ext` | Claude API、Bedrock、外接、MAX 号池 | 通常留空，外接可填 Claude 模型名 |
| Claude 逆向 | `free_2`, `free_2_new`, `free_2_wf` | AWSQ/Kiro、ANTI、Windsurf 等逆向 Claude | 留空；稳定性优先时不建议首选 |
| Codex/OpenAI | `vip_2`, `vip_2_cc`, `vip_2_remap`, `vip_2_azure`, `vip_2_image` | Codex Pro、Claude Code 调 OAI、Azure OpenAI、图像生成 | 多数填 `gpt-5.4` 或对应 GPT/图像模型 ID |
| Gemini/Grok | `vip_3`, `grok` | Gemini API、Grok | 按模型广场的模型 ID |
| 国产模型 | `vip_4`, `vip_4_ds`, `vip_4_ds_pro` | 国产混合、DeepSeek 官方、活动限时 DeepSeek | 按模型广场模型 ID |

来源：文档首页“令牌分组速查”。文档说“全部 21 个分组”，但当前页面文本可见我只读到 20 个，具体最新模型与倍率应以模型广场为准。([docs.micuapi.ai](https://docs.micuapi.ai/))

**选择建议**

- Claude Code 正常用 Claude：优先看 `vip_1_*` 官方/号池，不要默认选 `default`。Claude 类 `model` 通常可留空。([docs.micuapi.ai](https://docs.micuapi.ai/cc-switch))
- Claude 外接到第三方客户端：优先 `vip_1_ext` 或 `vip_1_max_ext`，Base URL 用 `https://www.micuapi.ai`，协议走 Anthropic Messages，并补 Claude CLI 风格 UA。([docs.micuapi.ai](https://docs.micuapi.ai/external-compat))
- Codex CLI：用 `vip_2`，Base URL 要带 `/v1`，推荐 `model = gpt-5.4`。([docs.micuapi.ai](https://docs.micuapi.ai/codex))
- Claude Code 调 OpenAI/Codex 模型：用 `vip_2_cc`，必须把模型改成 `gpt-5.4` 或其他 GPT 模型，不能继续写 Claude 模型名。([docs.micuapi.ai](https://docs.micuapi.ai/cc-switch))
- OpenClaw 多 Provider：Claude、Codex、国产模型要分别建 provider，分组、Base URL、UA 不能混用。([docs.micuapi.ai](https://docs.micuapi.ai/openclaw))
- 国产模型外接：`vip_4` / `vip_4_ds*`，通常要浏览器型 User-Agent。([docs.micuapi.ai](https://docs.micuapi.ai/external-ua))

**最容易踩坑的点**

- Claude 类 Base URL 不带 `/v1`；Codex/Grok 类通常带 `/v1`。([docs.micuapi.ai](https://docs.micuapi.ai/external-compat))
- 外接时只填 Key 不够，还要填对 `User-Agent`；缺失或混用 UA 常见结果是 `403 block` / `403 Forbidden`。([docs.micuapi.ai](https://docs.micuapi.ai/external-ua))
- `vip_2_cc` 是“Claude Code 壳 + OAI 模型”，不是 Claude 模型分组。模型名写错会触发不可用或模型错误。([docs.micuapi.ai](https://docs.micuapi.ai/cc-switch))
