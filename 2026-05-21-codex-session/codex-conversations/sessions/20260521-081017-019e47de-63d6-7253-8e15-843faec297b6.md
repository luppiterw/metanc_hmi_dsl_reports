```
REPL是什么
```

### Codex Response 1 / final_answer
`2026-05-21 08:55:44 +0800`

````
REPL 是 **Read-Eval-Print Loop**，直译就是“读取-执行-打印循环”。

在我们这里指的是 `metanc_plc_sim` 这个交互式终端模拟器：

```text
plc> di clamp_closed true
plc> tick
plc> state
plc> snapshot
plc> quit
```

它做的事是：

1. **Read**：从终端读一行命令，比如 `tick`
2. **Eval**：执行命令，比如推进一个 PLC scan
3. **Print**：把结果打印出来
4. **Loop**：继续等下一条命令

所以我说“REPL 改造”，意思是：终端交互界面继续保留 `tick/run/di/nrt/state/snapshot` 这些命令，但它自己不直接操作 PLC runtime，而是把命令转换成 `RuntimeCommand`，交给 `CommandExecutor` 执行。这样以后终端、测试、场景 runner、socket/SDK adapter 都能复用同一套 runtime command 层。
````
