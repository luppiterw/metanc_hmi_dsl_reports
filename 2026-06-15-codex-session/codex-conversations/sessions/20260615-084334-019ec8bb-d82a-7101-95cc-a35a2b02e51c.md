所以 `docker-compose.yml` 实际是两服务：

```yaml
services:
  drawio:
    image: jgraph/drawio:latest
    ports: ["8080:8080"]

  next-ai-draw-io:
    build:
      context: .
      args:
        - NEXT_PUBLIC_DRAWIO_BASE_URL=http://localhost:8080
    ports: ["3000:3000"]
    env_file: .env
    depends_on: [drawio]
```

- **MCP server 本身不要求 Docker**：它推荐的是 `npx @next-ai-drawio/mcp-server@latest`，通过 stdio 接 MCP client，本地起一个 embedded HTTP server，默认端口 `6002`。([github.com](https://github.com/DayuanJiang/next-ai-draw-io/blob/main/packages/mcp-server/README.md))
